# Inter-Containment Wormhole Model · Angle Scan

> **凌晨五点半的数据：宇宙的回返角，可能不是一个固定数字**

一个从「关系网络」本体论出发的离散宇宙学数值实验。代码开源，数据开放，结论可打脸。

---

## 核心发现（省流版）

SPUM（空间粒子宇宙模型）认为宇宙信息回返的最优角是 **137.5°**（黄金角）。

互含框架的虫洞模型（3+1D 离散因果网络）跑了 **k=3/6/12/26** 四组密度扫描，数据说：

| k | 最优角 | 最优 β | 137.5° | 109.5° | 70° | 物理图像 |
|---|--------|--------|--------|--------|-----|----------|
| **3** | **180°** | **0.9921** | 0.9449 | 0.9223 | — | 极简：对径回返最直接 |
| **6** | **130°** | **0.9798** | 0.9382 | **0.9786** | — | 中等：四面体角最优 |
| **12** | **70°** | **0.9767** | 0.9027 | 0.9273 | **0.9767** | 较密：锐角偏转最优 |
| **26** | **无** | **0.99+** | — | — | — | 富集：密度淹没角度 |

**关键事实：**
- **137.5° 从未进入前三。** 在所有 k 值中，黄金角的 β 始终在 0.90–0.94，平庸。
- **不存在单一「普适最优角」。** 最优角随连接密度 k 漂移：180° → 109.5° → 70° → 无峰值。
- **这意味着：** 如果宇宙存在一个「最优回返角」，它不是常数，而是**网络相变的序参量**——随密度变化而变化。

这比「找到一个固定最优角」更有科学价值。因为**可变的规律比固定的常数更难伪造，也更有解释力**。

## 实验设计

- **模型**：互含框架虫洞模型 v3（3+1D 离散网络，BFS 回返，链接间夹角约束）
- **网格**：N=8³ × 32（8GB 内存极限）
- **邻居**：Moore（26 方向）
- **核心参数 k**：每个节点最多保留 k 条连接（k=3,6,12,26）
- **扫描**：0°–180°，步长 10°
- **指标**：β（度规涌现度，0.80–1.20 为稳定，越接近 1.0 越优）

**为什么用 k 控制密度？**
- Moore 邻域有 26 个方向，但 v3 强制只选 k 个，优先保留链接间夹角 ≈ target 的组合。
- k 越小，网络越稀疏，角度约束越强。
- k 越大，网络越致密，角度信号被淹没。

- **Python**: 3.8+

### 核心实验命令

**密度-角度相图扫描（最核心）**
```bash
# k=3（极简，预期180°最优）
python scripts/g3duo_v3_angle_scan_v3.py 3 8 32 16 0.15 0.02 42 moore 0 180 10 3

# k=6（中等，预期109.5°最优）
python scripts/g3duo_v3_angle_scan_v3.py 3 8 32 16 0.15 0.02 42 moore 0 180 10 6

python scripts/g3duo_v3_angle_scan_v3.py 3 8 32 16 0.15 0.02 42 moore 0 180 10 26
```

## 参数说明

```
python g3duo_v3_angle_scan_v3.py DIM N Nt h w seed nbr ang_start ang_end step k
```

| 参数 | 含义 | 建议值 |
|------|------|--------|
| `DIM` | 空间维度 | 3（固定） |
| `N` | 空间网格边长 | 8, 10, 12 |
| `Nt` | 时间层数 | 32, 40 |
| `h` | BFS 最大跳数 | 16 |
| `w` | 虫洞概率 | 0.02 |
| `seed` | 随机种子 | 42, 123, 456 |
| `nbr` | 邻居类型 | `moore` (26方向) |
| `ang_start` | 扫描起始角度 | 0 |
| `ang_end` | 扫描终止角度 | 180 |
| `step` | 扫描步长（度） | 10, 5, 2.5 |
| `k` | 每个节点最大连接数 | 3, 6, 12, 26 |

**k 的含义（v3 核心）**:
- `k=3`: 最稀疏，角度约束最强 → 预期 180° 最优
- `k=6`: 中等稀疏 → 预期 109.5° 最优
- `k=12`: 较密 → 预期 70° 最优
- `k=26`: 无限制 → 预期无显著峰值

## 结果解读

跑完会生成 CSV，包含以下列：

| 列名 | 含义 |
|------|------|
| `target_angle` | 目标角度（度） |
| `beta` | 度规涌现斜率（0.80–1.20 为稳定，越接近 1.0 越优） |
| `R_mean` | 平均互含度（局部回返密度） |
| `stable` | 1=STABLE, 0=UNSTABLE |
| `eff_rate` | BFS 有效路径率 |
| `time_sec` | 该角度点运行时间 |

**按 `beta` 降序排列，看前 3 名：**

- **情况 A**: k=3 时 180° 最优 → 极简对径回返最直接
- **情况 B**: k=6 时 109.5° 最优 → 四面体角在稀疏条件下最优
- **情况 C**: k=12 时 70° 最优 → 锐角偏转在较密条件下最优
- **情况 D**: k=26 时无显著峰值 → 密度淹没角度信号
- **情况 E**: 不同 k 值的最优角不一致 → **密度-角度相图假说成立**

## 密度-角度相图假说（新增）

基于 N=8 的四组 k 值扫描，我们提出以下假说：

> **在离散因果网络中，不存在普适的「最优回返角」。最优角是连接密度 k 的函数，随网络相变而漂移。**

| 连接密度 k | 最优角 | 物理图像 |
|-----------|--------|---------|
| k=3（极简） | 180° | 伸出去、直接弯回来。对径回返是最简单的闭合方式。 |
| k=6（中等） | 109.5° | 需要一点偏转才能形成稳定环。正四面体的中心角恰好提供这种偏转。 |
| k=12（较密） | 70° | 网络更密时，更锐的偏转也能闭合，70° 成为新的最优解。 |
| k=26（富集） | 无 | 连接太多，角度约束被淹没，所有角度都稳定。 |

**宇宙学对应：**
- **早期宇宙**（高温高密度，k 高）：角度约束弱，全稳定 → 无物质类型分化
- **结构形成期**（局部冷却，k 降低）：角度约束显现 → 物质/暗物质/暗能量分化
- **晚期宇宙**（极度稀疏，k→3）：趋向 180° 对径回返 → 暗能量主导？

**如果 N=12 的大网格扫描复现同样的漂移序列，这个假说将获得数值支持。**

## 关于互含框架

**互含范畴**（Inter-Containment Category）是一个从「关系先于对象」出发的理论框架，核心假设：

> 宇宙不是由「东西」构成的，而是由「关系回返」自我显化的。

虫洞模型是它的数值实现——从纯粹的关系网络出发，不预设时空几何，让三维度规自己涌现出来。

已有成果：
- 度规涌现数值验证（β≈1.0，三维唯一稳定）
- R 值演化方程（R(z)=1-(1+z)/e，斩杀线 R*≈0.632）
- 宇宙学预热期预言（双峰/肩峰引力波谱）

当前目标：**电磁相互作用的几何化**。如果回返路径的最优角-密度相图能被锁定，物质-暗物质-暗能量的三分法就可能从一个「密度-角度」联合分布中自然浮现。

相关论文见 [Zenodo](https://doi.org/10.5281/zenodo.22025865)。
